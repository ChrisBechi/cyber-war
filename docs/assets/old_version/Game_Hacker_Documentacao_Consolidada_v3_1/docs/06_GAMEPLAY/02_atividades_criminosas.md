# Atividades Criminosas Opcionais

## Objetivo
Criar uma fonte de renda e progressão fora da história principal. O jogador deixa de ser apenas contratado e pode se tornar fornecedor de serviços no underground.

## Três economias
### 1. Trabalho contratado
Cliente → objetivo → pagamento.

### 2. Serviços anunciados
O jogador publica, dentro dos fóruns fictícios, categorias de serviço. A reputação determina volume, qualidade e risco dos contatos.

Exemplos de categorias abstratas:
- obtenção de informações;
- recuperação/acesso;
- análise de sistemas;
- indisponibilidade de serviço;
- dados corporativos;
- cracking;
- outros.

### 3. Operações próprias
Atividades de maior risco e potencial financeiro:
- scams simulados;
- mercado de dados;
- access brokering;
- cracking/keygens fictícios;
- informações corporativas;
- serviços de botnet fictícia;
- operações com criptoativos.

## Scams
Podem existir campanhas fictícias baseadas em:
- páginas falsas;
- anúncios falsos;
- promoções/promessas falsas;
- impersonation;
- phishing;
- typosquatting;
- pretexting.

A mecânica deve simular **persona, credibilidade, seleção de alvo, conversão, risco e consequência**, sem fornecer um kit operacional aplicável a fraude real.

## Transformação psicológica
No começo o protagonista quer provar habilidade. Depois percebe que golpes simples podem render mais que trabalhos tecnicamente difíceis. Isso reforça a passagem:
**talento → dinheiro → racionalização → crime**.

## Consequências
Atividades opcionais alimentam:
- reputação;
- dinheiro;
- contatos;
- inimigos;
- evidências;
- exposição;
- interesse policial;
- possíveis rotas narrativas.
