# Fundamentos de CLI de Rede

## Objetivo narrativo
Os comandos básicos ajudam a mostrar a evolução do protagonista do Windows para Kali/Linux e funcionam como linguagem recorrente de troubleshooting dentro da simulação.

## `ping`
Introduz a ideia de verificar se um host simulado está alcançável e observar resposta/latência. Surge cedo e depois reaparece naturalmente em troubleshooting, sysadmin e operações.

## `ipconfig`
Representa o hábito trazido do Windows. Pode aparecer primeiro como erro cômico após a migração para Kali.

## `ifconfig`
É apresentado no ambiente Linux simulado como parte da adaptação inicial do protagonista.

## Callback narrativo
No tutorial, a troca `ipconfig` → `ifconfig` é uma piada sobre hábitos antigos. Muito mais tarde, sob forte estresse, o protagonista pode repetir o erro por reflexo. O pequeno lapso serve como storytelling: por trás da reputação de `[NICKNAME]`, ainda existe o mesmo garoto do primeiro acesso.
