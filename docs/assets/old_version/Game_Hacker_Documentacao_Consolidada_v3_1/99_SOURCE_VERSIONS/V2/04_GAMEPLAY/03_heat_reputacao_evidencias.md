# Reputação, Heat e Evidências

## Reputação
Não é apenas um número. Afeta:
- quem responde;
- quem oferece trabalho;
- acesso a fóruns;
- acesso a guildas;
- preço dos serviços;
- confiança de clientes;
- respeito/rivalidade.

## Heat
Preferencialmente oculto. O jogador percebe por sinais:
- tentativas contra suas contas;
- avisos de GHOST;
- notícias;
- clientes nervosos;
- fóruns apagando tópicos;
- prisões;
- apreensões;
- interesse de investigadores.

## Evidências
O jogo registra silenciosamente:
- alvos;
- técnicas usadas;
- falhas;
- logs deixados;
- personas;
- contas;
- infraestrutura reutilizada;
- contatos;
- pagamentos;
- vítimas;
- serviços anunciados;
- crimes opcionais.

O objetivo é permitir que decisões de muitas horas atrás retornem de forma coerente.
