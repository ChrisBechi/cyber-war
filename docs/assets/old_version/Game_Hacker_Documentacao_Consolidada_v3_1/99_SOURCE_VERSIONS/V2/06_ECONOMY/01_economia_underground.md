# Economia Underground

## Gastos
Dinheiro pode ser usado para:
- peças melhores de PC;
- hardware especializado fictício;
- ferramentas;
- servidores/infraestrutura;
- internet;
- proxies;
- dados vazados;
- contatos;
- serviços;
- personas;
- acesso a mercados.

## Fontes de renda
- missões principais;
- contratos;
- cadeias de personagens;
- fórum;
- bug bounty;
- serviços anunciados;
- cracking;
- venda de informação;
- access brokering;
- atividades criminosas;
- operações de guilda.

## Regra narrativa
Ganhar dinheiro deve mudar de significado:
- $100 é enorme no começo;
- pagamentos de milhares viram rotina;
- operações de seis dígitos aparecem tarde;
- o protagonista progressivamente deixa de reagir a valores que antes mudariam sua vida.

## Risco
Maior retorno normalmente implica maior:
- exposição;
- evidência;
- severidade;
- inimigos;
- atenção policial;
- dependência de organizações.
