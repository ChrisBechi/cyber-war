# GAME HACKER - Apresentacao, Interface e Narrativa Ambiental

## Regra de camera

O jogador nunca sai da tela do computador. Acontecimentos fisicos sao percebidos por mensagens, chamadas, cameras, feeds, mapas, logs, arquivos e estado da conexao.

## Mae como presenca de fundo

- Sessao 1: `filho vou trabalhar / tem comida na geladeira` - resposta normal.
- Sessao 2: `vai dormir que horas?` - `ja vou`.
- Sessao 3: `voce nao janta mais comigo` - `to ocupado`.
- Sessao 4: `aconteceu alguma coisa?` - visualizada, sem resposta.
- Sessao 5: `filho?` - visualizada, silencio.

## Ritmo

Alternar operacoes tensas com respiros: forum, Gregory, mae, upgrades, navegacao e investigacao. O silencio e o estado `OFFLINE` podem ser tao importantes quanto uma sequencia de ataque.
