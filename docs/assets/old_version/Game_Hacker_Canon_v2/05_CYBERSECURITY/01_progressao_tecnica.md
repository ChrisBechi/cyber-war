# Progressão Técnica

## Gramática central
Footprinting → Scanning → Enumeration → Vulnerability Analysis → Exploitation → Post-Exploitation → Evidence/Data Collection → Covering Tracks.

No começo, o jogo ensina as etapas. Depois deixa de indicar a técnica e passa a apresentar apenas o objetivo.

## Curva
- Sessão 1: aprender.
- Sessão 2: praticar.
- Sessão 3: escolher.
- Sessão 4: combinar.
- Sessão 5: criar estratégia.
- Sessão 6: resolver sem orientação.

## APT
APT é um **arco operacional**, não uma técnica isolada:
reconhecimento → acesso inicial → persistência → movimentação lateral → objetivo → exfiltração → tentativa de ocultação.

## ICS/SCADA
Aparece tarde para mostrar que ações digitais podem atingir infraestrutura física. A representação é conceitual/simulada, sem instruções operacionais reais.

## Physical Security
CCTV, RFID, alarmes e acesso físico são operados/remotamente apoiados pela tela. Outros personagens executam ações no mundo físico; o jogador permanece no computador.
