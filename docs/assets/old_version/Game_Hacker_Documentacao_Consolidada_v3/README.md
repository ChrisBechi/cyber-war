# GAME HACKER — Documentação Profissional Consolidada v3

Esta versão consolida **integralmente a V1 e a V2**.

## Garantia de preservação
Nenhum arquivo das versões anteriores foi descartado. As duas árvores originais estão preservadas, sem substituição, em:
- `99_SOURCE_VERSIONS/V1/`
- `99_SOURCE_VERSIONS/V2/`

A árvore `docs/` é a documentação de trabalho consolidada: parte da estrutura profissional da V1 e incorpora os módulos novos da V2.

## Precedência
1. `docs/01_CANON/CURRENT_CANON_AMENDMENTS.md` — decisões mais recentes quando houver conflito.
2. Documentos canônicos detalhados da V1 em `docs/01_CANON/`.
3. Documentos de campanha/rotas/design atuais em `docs/`.
4. Suplementos V2 — complementam, não apagam, a versão detalhada.
5. `archive/` — material legado para consulta.
6. `99_SOURCE_VERSIONS/` — cópia integral das versões de origem para auditoria e recuperação.

## Objetivo
Adicionar e corrigir continuidade sem apagar ideias. Quando uma ideia antiga foi substituída (ex.: tio ligado ao submundo), ela continua preservada na origem, mas a regra canônica atual fica explicitamente marcada.
