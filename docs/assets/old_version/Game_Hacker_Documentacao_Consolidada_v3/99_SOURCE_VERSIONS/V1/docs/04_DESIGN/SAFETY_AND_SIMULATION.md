# GAME HACKER - Realismo, Simulacao e Isolamento

## Principio

> **Maximo realismo na aparencia e na experiencia. Maximo isolamento na execucao.**

Toda ferramenta, rede, servidor, vulnerabilidade, conta, arquivo, malware, payload, botnet, proxy, mercado ou sistema existe apenas na Internet ficticia persistente do jogo.

## Proibicoes de produto

Nenhuma mecanica pode:
- acessar arquivos reais do jogador;
- acessar contas reais;
- usar credenciais reais;
- escanear redes ou dispositivos reais;
- executar malware real;
- atacar infraestrutura externa;
- afetar outros dispositivos;
- transformar puzzles em ferramentas operacionais contra sistemas reais.

## Abstracao tecnica

Quando uma tecnica real inspirar uma missao, os elementos operacionais devem ser simulados, abstraidos ou substituidos por sintaxe, alvos, protocolos, enderecos e ferramentas pertencentes ao universo do jogo.
