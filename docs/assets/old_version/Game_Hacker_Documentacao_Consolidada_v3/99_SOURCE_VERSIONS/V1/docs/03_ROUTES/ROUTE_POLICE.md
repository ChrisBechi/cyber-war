# GAME HACKER --- ROTA FINAL: POLÍCIA

## Sessão 6 --- HUNTED

> **Princípio do arco:** NULL descobriu quem `[NICKNAME]` é. A polícia
> ainda precisa provar quem ele é.

A rota policial é construída silenciosamente durante a campanha.
Notícias sobre operações, prisões de usuários, fóruns derrubados e
investigações aparecem desde as Sessões 2 e 3 como ambientação. Para o
protagonista, são problemas dos outros --- até deixarem de ser.

Os dois desfechos desta rota são **CAPTURADO** e **DESAPARECIDO**.

uma identidade candidata: nickname, possível nome, fotografias, endereço

honeypot para confirmar, dentro da infraestrutura simulada, que aquela
pessoa realmente opera `[NICKNAME]`.

``` text

```


O anonimato acabou.

# 5. A DECISÃO DE MATAR NULL

O protagonista lembra dos contatos adquiridos no underground.

Procura um intermediário criminoso dentro da Deep Web fictícia e
contrata um assassino.

Alvo:

``` text

```

A cena não deve parecer uma missão técnica comum. É silenciosa e
desconfortável.

NULL, por sua vez, nunca acreditou que `[NICKNAME]` realmente faria
isso. Ele viu o script kiddie virar hacker, rival e Black Hat, mas ainda
acreditava existir uma última fronteira.

Quando ouviu:

> **"Eu vou te matar."**

Depois:


autoridades dele.

# 11. INVASÃO AO SISTEMA POLICIAL

avanço do caso e tentar apagar ou corromper parte dos rastros.

contra sistemas policiais reais.

Objetivo:


Ele consegue, dentro da narrativa:

-   remover algumas correlações;
-   inutilizar registros fictícios;
-   atrasar análises;
-   criar inconsistências;
-   apagar partes ainda não consolidadas;
-   descobrir quais operações estão sob investigação.
