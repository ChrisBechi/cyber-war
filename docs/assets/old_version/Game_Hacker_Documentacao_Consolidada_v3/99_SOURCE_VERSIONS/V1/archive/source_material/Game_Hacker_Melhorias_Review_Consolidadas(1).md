# GAME HACKER --- Melhorias Consolidadas após Review

> Documento complementar ao roteiro principal e à Rota da Máfia.\
> Objetivo: registrar as melhorias aprovadas no review sem substituir
> decisões narrativas já fechadas.

------------------------------------------------------------------------

## 1. Morte de NULL --- reforçar a transição moral

A decisão de contratar a morte de NULL permanece como o ponto em que o
protagonista atravessa uma fronteira irreversível.

O gatilho já definido continua:

> **NULL:** vou mandar tudo pra polícia.\
> **NULL:** você precisa pagar pelo que fez.
>
> **\[NICKNAME\]:** eu vou te matar.
>
> **NULL:** você não tem coragem.

NULL está blefando. Apesar da rivalidade, ele não pretende entregar o
protagonista à polícia. O protagonista, porém, não sabe disso.

### Melhoria

Entre a conversa com NULL e o contato com Mikhail, deve existir um curto
período de desespero. Isso evita que a decisão pareça instantânea.

``` text
NULL
OFFLINE
```

O protagonista tenta contato novamente.

``` text
MESSAGE NOT DELIVERED
```

Ele abre o HackPad e começa a considerar possibilidades:

``` text
POLICE?
IDENTITY EXPOSED?
LEAVE?
DELETE EVERYTHING?
NULL?
```

Pode chegar a escrever:

``` text
[NICKNAME]:
quanto você quer?
```

NULL continua offline.

O protagonista percebe que não consegue recuperar o controle da
situação.

Só então abre:

``` text
OPEN CONTACT
MIKHAIL
```

A decisão continua sendo terrível e impulsiva, mas agora nasce de uma
escalada visível de medo, paranoia e impotência.

## 2. Mikhail --- não revelar sua verdadeira identidade cedo demais

Antes da morte de NULL, Mikhail deve continuar sendo percebido como:

-   um cliente muito bem financiado;
-   discreto;
-   profissional;
-   recorrente;
-   misterioso;
-   alguém com muitos contatos e infraestrutura.

O protagonista pode suspeitar que existe algo maior por trás dele, mas
**não deve saber ainda que Mikhail pertence à máfia russa**.

Isso é fundamental para manter plausível a decisão de procurar Mikhail
quando NULL ameaça entregar sua identidade.

A progressão pré-NULL permanece:

``` text
TRABALHOS NORMAIS
↓
CONSEQUÊNCIAS ESTRANHAS
↓
PESSOAS SUMINDO
↓
EMPRESAS QUEBRANDO
↓
PADRÕES ENTRE TRABALHOS
↓
PAYLOAD NA PENÚLTIMA MISSÃO
↓
REDE MAIOR DESCOBERTA
↓
NULL ENCONTRA A MESMA ANOMALIA
↓
ALERTA
```

A conclusão do jogador deve ser:

> **"Mikhail está envolvido com alguma coisa grande."**

E não:

> **"Mikhail é o coordenador tecnológico de uma máfia internacional."**

------------------------------------------------------------------------

## 3. O momento de revelação da organização

Existe uma lacuna que precisa ser preenchida: depois da morte de NULL, o
protagonista precisa ter um momento claro em que finalmente entende para
quem está trabalhando.

Essa revelação não deve acontecer através de uma cutscene externa,
execução explícita ou exposição artificial.

Ela deve acontecer através da própria investigação digital.

Durante as seis ou mais missões pós-NULL, o protagonista começa a
encontrar:

``` text
MIKHAIL
↓
OUTROS OPERADORES
↓
EQUIPES
↓
INFRAESTRUTURA
↓
EMPRESAS DE FACHADA
↓
FINANCEIRO
↓
OUTROS BRAÇOS
↓
MEMBROS IMPORTANTES
↓
ORGANIZAÇÃO CRIMINOSA
```

No HackPad, o projeto de investigação cresce.

``` text
PROJECT: MIKHAIL
```

O protagonista começa a correlacionar:

``` text
██████ HOLDINGS
        │
        ├── ███████
        ├── ███████
        │
     MIKHAIL
        │
   CYBER OPERATIONS
```

Até surgir uma correlação forte:

``` text
MATCH FOUND
```

Depois:

``` text
ORGANIZED CRIME CONNECTION
CONFIDENCE: HIGH
```

Esse é o momento em que ele finalmente entende a dimensão do problema.

## 4. A descoberta torna a morte de NULL ainda pior

Assim que percebe quem Mikhail realmente é, o protagonista lembra de
NULL.

Ele consulta:

``` text
NULL
LAST SEEN: █████
```

Depois abre a conversa com Mikhail:

``` text
[NICKNAME]:
preciso que alguém desapareça.
```

``` text
MIKHAIL:
nome.
```

Agora ele entende retrospectivamente o peso do pedido.

Não é necessário que Mikhail confirme:

> "Nós matamos NULL."

O protagonista sabe o suficiente.

A ausência de confirmação torna a situação ainda mais perturbadora.

Essa descoberta também ajuda a iniciar a transformação de:

> **"Quem é Mikhail?"**

para:

> **"Como eu saio disso?"**

## 5. Project: EXIT --- gatilho emocional

O Project: EXIT não nasce de uma única informação.

Ele nasce da soma de:

-   descoberta da organização;
-   percepção de que Mikhail coordena equipes;
-   desaparecimentos;
-   empresas destruídas;
-   morte/desaparecimento de NULL;
-   comportamento cada vez mais controlador de Mikhail;
-   vigilância percebida por Gregory;
-   dimensão crescente da infraestrutura;
-   percepção de que o protagonista já não está apenas aceitando
    trabalhos.

A missão financeira posteriormente transforma o medo em certeza.

Quando Mikhail afirma que haverá outro trabalho depois dela, o
protagonista entende:

> **não existe aposentadoria voluntária.**

Então o Project: EXIT deixa de ser investigação e vira plano de
sobrevivência.

## 6. Final Secreto --- manter em aberto

O conceito do **Final Secreto --- O Ciclo** continua válido, mas ainda
não está tão desenvolvido quanto as rotas Polícia e Máfia.

Não deve ser fechado agora.

A prioridade é concluir:

1.  Sessões 2, 3 e 4;
2.  Sessão 5 e guerra contra NULL;
3.  transição completa para as rotas finais;
4.  Rota da Polícia;
5.  Rota da Máfia;
6.  personagens e consequências.

Depois disso, o Final Secreto deve ser reconstruído utilizando decisões
acumuladas durante toda a campanha.

Ele deve recompensar o jogador que realmente investigou:

-   a garota;
-   Gregory;
-   NULL;
-   as consequências das próprias ações;
-   as manipulações entre personagens;
-   a origem da cadeia de acontecimentos.

O final não deve parecer arbitrário ou depender de uma escolha isolada.

## 8. A mãe precisa permanecer presente

A mãe é importante porque representa a vida original do protagonista.

Ela não precisa virar personagem central. Pequenas interações
esporádicas são suficientes.

### Sessão 1

> **MÃE:** filho vou trabalhar\
> tem comida na geladeira ❤️

O protagonista responde normalmente.

### Sessão 2

> **MÃE:** vai dormir que horas?

> **PROTAGONISTA:** já vou

### Sessão 3

> **MÃE:** você não janta mais comigo

> **PROTAGONISTA:** tô ocupado

### Sessão 4

> **MÃE:** aconteceu alguma coisa?

Mensagem visualizada.

Nenhuma resposta.

### Sessão 5

> **MÃE:** filho?

Visualizada.

Nada.

A deterioração da relação acontece através da própria interface.

O contraste temático é importante:

> O protagonista passa a campanha inteira tentando fazer `[NICKNAME]`
> ser conhecido por milhares de desconhecidos enquanto abandona as
> pessoas que conhecem seu verdadeiro nome.

## 9. Função temática dos personagens

Os personagens centrais podem representar caminhos diferentes na
transformação do protagonista.

### Mãe --- quem ele era

Representa casa, infância, identidade real e a vida anterior ao
underground.

### Gregory --- quem ele poderia continuar sendo

Representa amizade, humanidade, vida normal e conexão emocional.

Gregory erra, mas nunca abandona verdadeiramente o amigo.

### NULL --- quem ele poderia ter sido

NULL possui conhecimento e talento comparáveis, mas não aceita
transformar tudo em crime apenas porque consegue.

Ele provoca, compete e possui ego, porém ainda mantém limites.

### Mikhail --- no que o talento pode transformá-lo

Mikhail não vê o protagonista como amigo ou rival.

Vê talento como recurso.

Para NULL:

> `[NICKNAME]` é um adversário.

Para Gregory:

> ele é um amigo.

Para sua mãe:

> ele é um filho.

Para Mikhail:

> ele é um operador.

Essa diferença deve ficar cada vez mais perceptível.

## 10. Anonymous e a busca pela elite

A admiração do protagonista pelos Anonymous e por grandes grupos deve
continuar sendo semeada desde as primeiras sessões.

Pode aparecer através de:

-   tópicos;
-   notícias;
-   feitos atribuídos a grupos;
-   debates;
-   operações coletivas;
-   comentários de usuários;
-   referências históricas dentro do universo do jogo.

O protagonista começa desejando participar de grupos pequenos.

Depois quer entrar em grupos melhores.

Depois quer participar das maiores operações.

Finalmente quer que seu nickname seja reconhecido pela elite.

Anonymous não deve funcionar como:

``` text
APPLICATION
JOIN ANONYMOUS
```

A ideia continua sendo trabalhar com guildas, grupos e coalizões
descentralizadas que se unem em determinadas operações.

A admiração serve principalmente ao arco de ego:

> **"Quero que `[NICKNAME]` seja conhecido por essa gente."**

------------------------------------------------------------------------

## 11. O conflito entre anonimato e fama

Esse continua sendo um dos temas centrais da campanha.

O protagonista quer duas coisas incompatíveis:

``` text
QUE TODOS CONHEÇAM [NICKNAME]
+
QUE NINGUÉM CONHEÇA QUEM ESTÁ POR TRÁS DE [NICKNAME]
```

Quanto maior sua fama:

-   mais atenção recebe;
-   mais contratos aparecem;
-   mais inimigos cria;
-   mais investigadores surgem;
-   mais pessoas tentam descobrir quem ele é;
-   mais difícil fica proteger sua identidade.

O nickname começa como proteção.

Depois vira símbolo de ego.

Finalmente vira uma prisão.

## 13. Objetivo das Sessões 2--4

As próximas sessões precisam construir progressivamente:

### Sessão 2

Primeiros trabalhos reais.

Ainda pequenos.

-   investigação;
-   identificação;
-   informações;
-   acesso a e-mail;
-   derrubar perfil;
-   pequenos ataques;
-   primeiros pagamentos relevantes.

A última missão é a primeira invasão realmente detalhada.

Ela inicia a transformação para black hat.

### Sessão 3

O protagonista entra em um grupo hacker pequeno.

Começa a:

-   participar de operações coletivas;
-   ganhar reputação;
-   conhecer outros hackers;
-   desejar chegar à elite;
-   abandonar Gregory;
-   buscar fama;
-   ganhar mais dinheiro;
-   competir cada vez mais com NULL.

Gregory percebe que o amigo está mudando.

O protagonista começa a deixar de responder.

### Sessão 4

O crime deixa de ser exceção.

Vira profissão.

O protagonista já possui:

-   infraestrutura;
-   contatos;
-   reputação;
-   dinheiro;
-   inimigos;
-   clientes recorrentes;
-   conhecimento;
-   hábitos de ocultação.

É aqui que o jogador precisa perceber que o garoto da Sessão 1
praticamente desapareceu.

A Sessão 4 deve preparar emocionalmente a guerra e a paranoia da Sessão
5.

## 14. Objetivo da transformação moral

Quando o protagonista finalmente escreve:

``` text
[NICKNAME]:
preciso que alguém desapareça.
```

o jogador não deve pensar:

> **"Ele mudou do nada."**

A reação desejada é:

> **"Olha onde esse garoto chegou."**

Essa frase representa o teste definitivo para o desenvolvimento das
Sessões 2, 3 e 4.

Se a decisão de matar NULL parecer impossível para o personagem que o
jogador acompanhou, faltou desenvolvimento.

Se parecer terrível, chocante, mas compreensível diante de tudo que ele
viveu e se tornou, a progressão funcionou.
