# GAME HACKER — Documentação Consolidada v2

## Visão
**Game Hacker** é um thriller de investigação, mistério e cybersecurity para navegador, apresentado inteiramente pela tela do computador do protagonista.

O jogador acompanha um jovem de 17 anos que começa por curiosidade técnica e, ao longo de seis grandes arcos, entra em comunidades, ganha reputação, transforma conhecimento em dinheiro, cruza limites morais, entra no underground, participa de grupos hackers, enfrenta NULL, chama a atenção da polícia e pode terminar preso a uma organização criminosa internacional.

## Regra absoluta de execução
O jogo busca **máximo realismo na aparência e na experiência, máximo isolamento na execução**.

Todos os sistemas, redes, empresas, governos, contas, dispositivos, pessoas, serviços, arquivos e alvos existem somente na infraestrutura fictícia e persistente do jogo. Técnicas reais podem ser representadas conceitualmente, inclusive CVEs históricas selecionadas, mas o jogo não deve se transformar em um manual operacional reutilizável contra sistemas reais.

## Estrutura macro
1. **SCRIPT KIDDIE** — curiosidade, V1/V2, fórum, Gregory, NULL, VEX.
2. **REPUTATION** — clientes, dinheiro, serviços, OSINT, web, engenharia social.
3. **BLACK HAT** — guildas, operações em equipe, mobile, AppSec, afastamento de Gregory.
4. **GHOST** — underground avançado, malware, zero-days, mercado de acessos e identidade.
5. **EXPOSED** — guerra com NULL, Mikhail, revelação da identidade, escalada.
6. **HUNTED** — polícia ou máfia, sobrevivência e finais.

## Filosofia GTA
As sessões não são apenas capítulos. Cada uma abre um **novo mundo social e técnico**. Personagens importantes abrem novas possibilidades, atividades e cadeias de missões. O miolo é não linear; a missão final de cada sessão é fixa, canônica e conecta a próxima.

## Progressão temática
Curiosidade → habilidade → reputação → dinheiro → ego → poder → crime → paranoia → sobrevivência.
