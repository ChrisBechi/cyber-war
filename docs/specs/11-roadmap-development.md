# Spec 11 — Roadmap

## M0 — Tooling

Tauri/React/Rust abrem, CI verde, SQLite inicializa, 5 slots existem, NSIS/MSI compilam.

## M1 — PC básico

Desktop, WindowManager, terminal, VFS, file manager, arquivos dinâmicos, atalhos, editor simples, save/load.

Critério: criar `notes.txt` no terminal, abrir no file manager, editar, fechar o jogo e reencontrar depois.

## M2 — Virtual Network

Hosts, subnets, services, users, sessions, ping, scanning virtual e SSH virtual.

## M3 — Narrative shell

Fórum, mensageiro, contatos, notificações, eventos, dinheiro/reputação e MissionEngine.

## M4 — Vertical Slice Sessão 1

Intro, menu, V1 e save slots. Depois V2, Sem Internet, Pendrive, VEX e Garota.

## M5 — Fidelity

File manager completo, settings, workspaces, processos, permissões, sudo/root, Monaco e navegador fictício.

## Não fazer cedo

Multiplayer, launcher próprio, cloud backend, workshop, VM Kali, Bash real, rede real ou implementar toda a Sessão 3 de uma vez.
