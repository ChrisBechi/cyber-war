# GAME HACKER - Precedencia de Documentos

## Nivel 1 - Canon global

1. `docs/01_CANON/CANON_RULES.md`
2. `docs/01_CANON/NARRATIVE_BIBLE.md`
3. `docs/01_CANON/CHARACTER_BIBLE.md`
4. `docs/01_CANON/CONTINUITY_AND_CAUSALITY.md`

## Nivel 2 - Especificacao de campanha

Documentos de `docs/02_CAMPAIGN` e `docs/03_ROUTES` prevalecem sobre rascunhos antigos quando tratam especificamente da mesma sessao/rota.

## Nivel 3 - Design transversal

`docs/04_DESIGN` define regras de sistemas narrativos, apresentacao e isolamento tecnico.

## Nivel 4 - Arquivo historico

`archive/source_material` existe para rastreabilidade. Nao e fonte de verdade quando contradiz documentos acima.

## Regra para novas alteracoes

1. Registrar a decisao em `CANON_RULES.md` se afetar o canon global.
2. Atualizar o documento especifico afetado.
3. Atualizar `CHANGELOG.md`.
4. Se a decisao invalidar material antigo, manter o original no archive, sem apagar historico.
