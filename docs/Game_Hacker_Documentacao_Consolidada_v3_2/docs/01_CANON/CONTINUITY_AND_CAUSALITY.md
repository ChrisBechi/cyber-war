## Regra de Gregory

Gregory fornece informacoes por culpa, intimidade e ingenuidade social. Nunca existe decisao consciente de entregar o amigo.

## Regra do honeypot

O honeypot nao revela magicamente nome, foto ou endereco. Esses dados ja existem como identidade candidata. O honeypot apenas confirma de forma exata que aquela pessoa opera `[NICKNAME]`.
