# Fundamentos de CLI e Rede

## Prólogo / First Boot — CLI de sistema
O tutorial inicial não introduz troubleshooting de rede. O foco é adaptação ao Linux/Kali-like e navegação pelo filesystem.

Comandos básicos podem incluir: `pwd`, `ls`, `cd`, `mkdir`, `rm`, `cp`, `mv`, `cat`, `clear` e `wget` quando houver contexto de download por terminal.

## Sessão 1 — missão de Wi-Fi
É aqui que entram os primeiros comandos de rede.

### `ping`
Usado para verificar se um host/alvo simulado responde e introduzir conectividade/latência.

### `ipconfig`
Representa o hábito trazido do Windows.

### `ifconfig`
Aparece no ambiente Linux/Kali-like durante a tarefa de rede.

## Callback narrativo
Na missão de Wi-Fi, `[NICKNAME]` pode digitar `ipconfig` por hábito e receber erro antes de lembrar de `ifconfig`. Muito mais tarde, sob forte estresse, ele pode repetir o lapso por reflexo.
