# GNU Coreutils command messages

The observable C-locale help and version strings in this directory were captured
from GNU Coreutils 9.7 (Alpine package 9.7-r1). GNU Coreutils is copyright
Free Software Foundation, Inc. and distributed under GPL-3.0-or-later.

Upstream: https://www.gnu.org/software/coreutils/

Source: https://ftp.gnu.org/gnu/coreutils/coreutils-9.7.tar.xz

License: https://www.gnu.org/licenses/gpl-3.0.html

Only invocation and version placeholders are substituted. These are static public
interface messages; command results are computed by the virtual implementation.
The reference captures retain the original bytes and author/license banners.
