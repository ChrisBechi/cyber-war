# Flat Remix icons

Original, unmodified SVG assets from [Flat Remix](https://github.com/daniruiz/flat-remix),
theme **Flat-Remix-Blue-Dark**, commit `e7de6c346da46e008987228f363b0eae6e638637`.

Author: Daniel Ruiz de Alegría and the contributors listed in AUTHORS.txt.
License: GNU General Public License v3.0 (LICENSE.txt).

Upstream symbolic links are resolved into the original SVG bytes. See sources.json for
each requested path, resolved source path, and SHA-256. Display dimensions and symbolic
colors are applied by CSS; the folder artwork and its emblems are unchanged.
